התקנת המכחול המכני

מה להכין, איך להתקין ב-Mac או ב-Windows, ואיך להפעיל בפעם הראשונה. ההתקנה לוקחת כעשר דקות.

מה צריך לפני השיעור

  • מחשב Mac או WindowsMac: כל מחשב, גם עם שבב Apple וגם עם Intel. Windows: גרסת ‎64-bit.
  • חיבור לאינטרנטלהורדה, להפעלת הקוד, ולכל יצירה של תמונה.
  • קוד הפעלהמקבלים אותו בשיעור. קוד אחד למחשב אחד: אחרי שהופעל, הוא נקשר למחשב שלך ולא יעבוד באחר.
  • מפתח API של ספק תמונות, עם קרדיט בחשבוןלפי הספק שנבקש בשיעור (למשל OpenAI). כל יצירה עולה כסף לפי התעריף של הספק, ומשולמת ישירות אליו. אם הספק מבקש לאמת את החשבון, עשה את זה לפני השיעור.

הורדה

הורדה ל-Macmechanical-brush-0.4.0.dmg · 236MB הורדה ל-Windowsmechanical-brush-setup-0.4.0.exe · 133MB

התקנה ב-Mac

  1. פתח את הקובץ mechanical-brush-0.4.0.dmg שהורדת.
  2. גרור את The Mechanical Brush לתיקייה Applications.
  3. פתח את האפליקציה מתוך Applications.

בפעם הראשונה macOS יעצור ויגיד שאי אפשר לאמת את המפתח של האפליקציה. זה צפוי: האפליקציה עדיין לא רשומה אצל Apple. כדי לפתוח אותה:

  1. לחץ סיום (או אישור) בהודעה.
  2. פתח את הגדרות המערכת ← פרטיות ואבטחה.
  3. גלול למטה עד לשורה על The Mechanical Brush ולחץ פתח בכל זאת.
  4. אשר עם הסיסמה של המחשב (או Touch ID), ולחץ שוב פתח.

מהפעם השנייה האפליקציה נפתחת רגיל.

התקנה ב-Windows

  1. הפעל את mechanical-brush-setup-0.4.0.exe שהורדת.
  2. אם מופיע מסך כחול של Windows protected your PC (המחשב שלך מוגן): לחץ More info (מידע נוסף), ואז Run anyway (הפעל בכל זאת).
  3. ההתקנה רצה לבד ופותחת את האפליקציה בסוף. אין צורך בהרשאות מנהל.

הפעלה ראשונה

  1. במסך הפתיחה לחץ על התמונה כדי להמשיך.
  2. קוד רישוי: הדבק את הקוד שקיבלת ולחץ הפעל. צריך חיבור לאינטרנט.
  3. מנוע ומפתח: בחר את המנוע שנבקש בשיעור, הדבק את מפתח ה-API ולחץ התחל. המפתח נשמר מוצפן במחשב שלך, ולא נכנס לקבצי הפרויקט.
  4. זהו. אפשר לפתוח תמונה ולהתחיל.

"קוד לא קיים"
בדוק שהדבקת את כל הקוד, בלי רווח בהתחלה או בסוף.
הודעה על קרדיטים או על מכסה (quota)
נגמר הקרדיט בחשבון אצל ספק התמונות. טען קרדיט באתר של הספק ונסה שוב.
"המנוע לא ענה בזמן"
הבקשה לקחה יותר מדי זמן ובוטלה, ולא נוצרה שכבה. ייתכן שהספק בכל זאת חייב עליה, אז בדוק בחשבון אצלו לפני שתריץ שוב.
מסך "משהו השתבש בתצוגה"
לחץ טען מחדש. העבודה שלא נשמרה נשמרת אוטומטית, והאפליקציה תציע לשחזר אותה.
